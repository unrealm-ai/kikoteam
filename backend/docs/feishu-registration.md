# 飞书扫码接入

接入登记属于 Platform；不调用 Engine。已有渠道配置、身份代际及 Hub 同步仍见 [渠道配置](channel-configuration.md)。登记 `connected` 只表示已验证并保存配置，不等于 Hub 长连接在线或真实消息已收发。

## 等待与检查

`/api/v1/workspaces/{workspace_id}/agents/{agent_id}/channels/feishu/registration` 的 GET 查询状态；POST 使用 `Idempotency-Key` 创建登记。登记下 `poll`、`retry`、`cancel` 均为 POST。工作区 owner/admin 授权及发起管理员归属在状态写入前重新校验。

本进程保存首次等待集合，每秒推进，最多 4 个并发。浏览器关闭不取消本进程首次等待；收到凭据后自动进行一次诊断。数据库版本认领保证浏览器与后台同时兑换或检查时仅一个获执行权。不是持久化自动恢复任务：进程重启后 pending 在读取/操作时转为 interrupted，不自动兑换；已保存凭据可以由前端恢复检查。

- `awaiting_confirmation` 按提供方间隔兑换；pending/slow_down 仍是同一次授权。
- `credentials_saved` 密钥加密保存在登记中；基础检查成功才原子创建渠道绑定并清除登记密钥。
- 基础接入仍待完成或全员通讯录设置仍待处理时，后台按持久化的 5、10、20、30、60 秒退避时间推进，浏览器只读进度。持久租约与登记版本防止多副本重复检查，进程退出后可接续。认证失败、绑定变化、应用已占用或发起管理员撤权会阻断登记复查。已绑定应用的只读权限更新由独立观测任务负责。
- `auto_check`、`next_check_at`、`check_attempts`、`auto_retry_blocked` 为可选字段。GET 不调用外部接口。
- cancel 只取消尚未收到凭据的等待；不删除、吊销已收到的凭据或配置。
- 诊断失败时，页面展示失败步骤和飞书返回的错误码、消息。旧登记只有本地错误码时，点击“重新检查”可更新诊断。自动检查已停止时页面停止轮询。
- 已保存凭据、尚未绑定且检查失败的登记支持“重新授权”。创建请求携带旧登记的 `replace_registration_id`，在同一事务中结束原登记、清除其本地密钥并创建新登记。省略 `all_contacts` 时沿用旧登记的选择。重复发送同一幂等键只返回同一登记。再次扫码创建新的飞书应用，旧应用保留在飞书。
- 在途兑换结果未知不重复兑换。检查超时允许重新执行只读检查，版本保护阻止迟到结果覆盖新状态。

## 权限与通讯录范围

飞书个人版可以只返回非空的 `user_ids`。接入检查和通讯录同步都接受仅有用户或仅有部门的授权范围。未披露范围、无法解析或仅包含不支持的用户组时，检查仍会报告错误。

新登记快照保存 `conversation-business-v3` profile。基础聊天/通讯录为必须；消息群、组织、文档、多维表格、日程、待办、会议妙记、审批、通讯录范围管理为扩展。全部使用 tenant 身份，不将其当作个人 OAuth。预申请不表示工具已实现，也不赋予任意资源访问权。

`permission_groups` 返回每组和每项 granted / missing / unknown，不将缺失或不完整清单伪装已授权。扩展检查只刷新权限清单，保留原完整验证时间，另用 `permission_checked_at` 记录清单时间。

员工页扫码新建默认申请 `application:application.contacts_range:write`，由管理员在飞书授权流程中确认。员工页创建请求省略 `all_contacts`，使用后端默认值 `true`。该权限获批后，后台只为该次登记新建的应用设置一次全员范围，并触发通讯录同步。扫码登记沿用发起时的权限清单。认证取 token 后、PATCH 发出前再次检查管理员、登记版本和绑定。连接后复查锁定同一绑定及凭据代次。

范围状态为 waiting_permission、applying、applied、failed 或 uncertain。发送前持久化 applying。发送结果未知或进程崩溃遗留 applying 视为 uncertain，需要在飞书后台核对。基础接入可先完成，后台继续检查待审批的范围权限。员工使用名单由统一使用策略管理。

绑定的 GET 返回独立的权限诊断及目录状态。权限检查任务在保存或更新凭据时创建，按连接代次和租约发布结果，扫码和手填共用。权限就绪时每五分钟重新观测，基础权限未就绪时按三十秒重试。已刷新范围由独立目录快照提供，外部读取确认为拒绝时淘汰旧证据。

## 验证边界

合成 provider、隔离 PostgreSQL 状态机和 HTTP transport 测试覆盖并发、权限撤销、换绑、重启、范围未知不重放等；它们不替代真实租户扫码授权、权限审批和消息收发验收。
