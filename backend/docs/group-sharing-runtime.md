# 群共享运行时历史读取

本文说明本轮新增的受控读取路径，不承诺沙箱 shell、任意网络或外部 MCP 的完整数据防泄漏。

运行工具只接受当前 Task/Input 的独立签名凭据。可读来源是当前任务真实来源群的独立 self-grant，以及首次列举时冻结的直接授权边，与当前策略、绑定、任务分配及实际会话受众再次相交；模型不能提交原始群 ID、绑定或 provider cursor 获得授权。系统结果不是授权主体。

飞书/Web接受合法起止时间；企微另外要求近7天范围。历史查询冻结来源引用、策略版本、Input、起止时间与截止。读取先创建服务端 query，后台按授权租约获取供应商单页；Web 直接查询本地共享消息。模型用 query ID 取结果/继续，供应商游标和企微未消费的页内记录只保存在服务端。同页重读不会更换快照，过期或撤权后缓存也不可读。

来源/派生限制属于真实目的群或人，而非单次模型输入。跨群正文返回前，同一事务重新检查来源及其已有派生来源是否均直接授权给当前受众，并持久化目的地累计来源和读取审计。A→B、B→C 不自动得到 A→C；如果 B 已读取 A，C 再通过该历史服务读取 B，必须同时具备 A→C 的直接授权。约束跨员工到达同一真实目的地持续存在，不能靠换员工清除。

## 渠道差异与限制

- Web：读取本地共享群消息，以服务端序号分页，不读取 Task 文件或其他会话。
- 飞书：使用授权绑定读取主群的指定时间范围，真实供应商消息 ID；不隐式展开群话题、下载附件或读取其他群。
- 企微：仅近7天历史，秒级北京时间；返回记录 ID 是本次查询局部引用，不是供应商消息 ID。保留相同文本，不按正文去重。供应商整页超过工具页大小时缓存剩余记录，不能跳过。
- 钉钉：当前接入没有群历史能力，明确返回不支持，不假造历史。

当前页面上限50条，查询最多10页、64KB可见内容，每个运行 Input 最多20个查询页、128KB可见内容。全部查询范围冻结，授权和来源变化、租约过期、异常分页或读取失败不会被标成成功。这里只返回文本投影，非文本为占位提示。

## 工具与执行身份

执行 Agent 通过 Manager 的 `/mcp/group-history` 调用 `group_history_list_contexts`、`group_history_read_messages`、`group_history_get_query`。凭据与任务委派工具分域签名，绑定 Engine、任务会话、assignment 和 generation；每次调用重验当前运行 Input。只有带真实会话受众的执行任务可用，TaskSpace、定时/Hook 系统结果不能凭空获得会话共享权。当前来源主群可获得独立 self-grant，不需要伪造共享策略；同样重验当前成员、绑定和来源 lineage，话题不隐式扩成主群自读。自身群历史不会因为过往入站共享边撤销而整体封禁，因为它不是新跨群披露；已有来源标记仍保留，后续其他群读取时仍受派生限制。

策略来源授权在首次列举时冻结，此后新增策略不能扩张同一 Input 权限；删除、禁用、版本变化和主体撤权仍参与后续授权检查。撤权并发以最终数据库授权检查时刻为准，不承诺已返回正文的撤回或网络发送与配置更新的全局线性化。

## 本轮验证边界

真实隔离 PostgreSQL 覆盖直接授权、派生来源限制、跨 Input 拒绝、冻结权限不扩张、策略撤销、停止执行、当前群 self-grant、Web 文本分页及成员移除。MCP HTTP 覆盖真实运行凭据、Cookie 拒绝和伪造作用域参数；Engine 覆盖仅会话执行任务注入 MCP。供应商返回页在授权测试中为模拟数据，不能据此声称完成飞书或企微实号端到端验收。
