# 人工确认的外部私聊投递

停稳且待答复的问题可以通过已绑定渠道主动通知准确确认人，不需要虚构用户入站。Manager 使用每个问题 ID、版本和完整确认人身份的唯一通知记录；Hub 租约领取后，Manager 重新核验原任务授权、当前问题与确认人、渠道绑定、租户和版本。发送前再次检查。企微只接受已通过核验的回调身份；搜索 ID 不作为目标。

飞书将 `open_id` 作为私聊目标。只有发送应答包含真实消息 ID 和私聊 ID，才持久记录可用于匹配引用的证据。钉钉先记录发送受理，再使用已知渠道请求键做有界只读查询。企微保留当前正式连接中对应发送的 ACK，不把它当作消息 ID。三个渠道仍可按问题编号答复。

未授权发送的租约可以过期并重新领取。授权后的发送结果不明时，不自动重发；迟到的同一尝试回执可修正投递事实，不因此重开问题或恢复任务。日志无问题正文和渠道凭据。上线启用前需核查旧待确认的未答积压；真实三渠道送达须独立验收。
