# Platform 员工基础管理

本期交付员工列表、创建、详情、基础配置保存与启停标志；渠道、权限名单、能力包、人工确认、聊天及真实 Agent 执行尚未迁入，不展示为可用功能。

- 所有工作区有效成员可读；仅 owner/admin 可写。复用 Cookie 登录与 CSRF 校验。
- `name` 必填，`role`（职责简介）、`avatar`（头像预设标识）、`instruction`（岗位行为规范）允许空，创建页面只填写职责，岗位行为规范在详情编辑。固定 Pi，不接受引擎或思考参数字段。
- 显式引用同工作区已启用且验证通过的 `model_profile_id`，不要求持有密钥（免密模型也可通过真实测试）。工作区默认模型仅供创建页预选，后续修改默认值不切换员工引用。
- 已绑定模型被停用/撤销后，员工仍可读取并改名、修改岗位行为规范和停用；响应 `model_available=false`。换绑或启用必须选用可用模型。
- 每次配置保存推进 `version` 和 `config_version`，生成不可变配置记录；启停只推进 `version` 和 `admission_epoch`。重复提交同一启停目标不产生额外版本。PATCH 必须带当前 `version`，并发竞争仅一方成功，不能自动覆盖冲突。
- 创建默认 enabled；这仅代表配置上的接入意愿，不代表 Engine、渠道已连接或可以聊天。停用后拒绝新输入、允许当前轮收尾的运行语义由后续 Manager/Engine 接入落实，本期未模拟执行结果。
- 本期不提供删除，避免尚未定义的会话、历史及引用生命周期处理。

## 数据与接口

迁移 `000006_platform_agents.sql` 由 Event Hub 统一执行。只新增 `platform_agents` 当前资源表与 `platform_agent_versions` 不可变配置表，不清理原账号、工作区或模型数据；模型引用具有工作区复合外键。Backend 不自行执行迁移。

接口契约见 [OpenAPI](../contracts/openapi.yaml)。`GET/POST /api/v1/workspaces/{workspace_id}/agents` 与 `GET/PATCH .../{agent_id}`；名录每页请求 20 条，接口省略页大小时返回最多 50 条，指定页大小上限 100，按 created_at DESC/id DESC 稳定分页，包含停用员工。创建普通 CRUD 不自动重试；省略 PATCH 字段保留原值，null 和未知字段拒绝。启停与配置分开提交。

名录支持按名称或职责进行不区分大小写的字面子串搜索 `q`，并按 `enabled` 筛选。响应的 `total` 为两项条件都满足的人数，`status_counts` 为同一搜索词下分别启用和停用的人数。所有有效工作区成员读取相同的 `card_resources`，包含已绑定的 IM 渠道类型、能力包数量和触发器总数。未绑定渠道时返回空数组，无能力包或触发器时对应数量为 0。数量包含已停用的配置，渠道图标只表示已有绑定。列表与详情继续共用员工 ID。

`version` 是整个资源的乐观并发版本；`config_version` 是员工配置快照版本；`admission_epoch` 是未来输入准入的代次，三者不能混用。固定 Pi 是本期协议，不从前端任意配置读取。

## 员工使用范围简化与旧配置复核

员工使用范围只有一个跨渠道人员策略：`all` 配人员/部门黑名单（allow 必须为空），或 `allowlist` 配人员/部门白名单（deny 必须为空）。不新增群 allow/deny；飞书、钉钉部门支持包含子部门，企微和 Web 不支持部门。渠道身份仍按 binding 和 identity epoch 校验。

`group_members_enabled` 是独立开关，默认 true；开启仅让可信群成员绕过人员白名单，不绕过人员/部门黑名单、当前群成员资格或渠道身份校验。关闭后群内同样执行完整人员规则。不得因修改其他设置重置已保存的 false。

历史群名单、all 携带 allow、allowlist 携带 deny 仍由既有 SQL 解释，不做清空或自动改写。PATCH usage-config 带当前 version 可以原样保留历史 access 并修改触发/历史设置；名单顺序调整视为不变。变更历史 access 默认返回 `409 usage_policy_requires_review`。管理员明确复核后，可在请求顶层传 `replace_legacy_access: true`，仅允许将旧不可表示策略替换为合法新模式。该标志不持久化、不返回，不能绕过版本、管理员身份及人员引用校验。正常策略不得传 true。

这一调整复用现有投影和运行权限 SQL，不需要数据迁移；旧群限制保留在投影中直到明确替换。未执行任何线上存量配置清理。
