# Platform 模型配置与接入诊断

本文维护已实现的工作区自备模型配置及其诊断。官方模型与积分由 [Platform modelproxy 子模块](model-proxy.md) 提供。选择场景扩展现有模型列表，后台自动装配员工代理 Key，不替换本页的自备模型管理与授权规则。

本模块在 `platform/controller → service → repository / integration` 下实现，Web 使用同域 Cookie/CSRF 的 `/api/v1/workspaces/{workspace_id}/model-profiles`。机器契约见 [OpenAPI](../contracts/openapi.yaml)；模型是一条具体型号的完整调用配置，不拆分服务连接与型号资源。Engine 尚未接入，本期不能宣称真实任务已能使用这些配置。

## 接入与保存

- 支持 `chat_completions`、`openai_responses`、`anthropic_messages`。裸域名统一为 `/v1`；显式非根路径保留。探测和持久化共用 `integration.NormalizeModelEndpoint`，存储规范化基地址。未来 Engine 必须消费该协议及规范化地址，不重新猜测地址或固定另一种协议；需另验收实际 Harness 请求。
- 只接受 HTTPS 服务，保留企业内网 HTTPS 地址；部署方通过网络出站策略限制可访问的模型服务。禁止 URL 用户信息、query、fragment、重定向。loopback HTTP 仅 Go 测试构造器显式启用，不向用户请求或默认部署暴露。
- 测试输入均为合成内容，不发送真实会话。文字与图片并行，分别设置 **20 秒 / 40 秒** 超时；HTTP handler 45 秒，服务端写响应 50 秒，Web 请求 50 秒。失败不会自动重试模型请求。
- 文字测试要求正常终止且输出 `OK`。图片采用随机颜色方块和四位数字；核对形状、颜色、数字后才记 `passed`。明确返回不支持图片才记 `unsupported`；超时、鉴权、协议错误、答案不匹配等均为 `unknown`，不武断判断不支持。
- 页面分别展示实际输出、耗时、HTTP 状态及安全问题码。上游错误正文不回显；成功输出遮盖密钥/Token，并限制长度。日志不记录请求/响应正文、凭据和测试回执。
- 只有文字通过才能保存。图片的 `passed / unsupported / unknown` 均可保存，能力状态依据实测，不使用前端复选框冒充实际能力。

## 回执与并发

同一工作区、同一操作者最多一个在途探测，数据库时钟生成的50秒租约跨Backend实例仲裁；正常结束/取消释放自身租约，进程崩溃后到期可接管，旧请求不能释放新租约。另使用现有持久化限频记录限制每操作者每工作区10次/分钟，429需稍后重试。图文两个case仍并行。

通过文字测试后生成随机回执，数据库仅保存 Token 哈希及 HMAC 配置摘要，10 分钟过期。摘要覆盖工作区、操作者、编辑目标及版本、名称/说明、协议、规范化地址、型号、有效密钥。前端修改任一配置后丢弃回执；服务端重新核验，不能伪造或使用另一管理员、另一工作区的回执。

更换基地址时必须显式重填凭据或明确选择无需认证，不把旧密钥自动转发到新目的地。编辑时省略 `api_key` 表示保留旧密钥，显式空字符串表示无需认证；不返回掩码假密钥要求用户回传。模型测试网络调用在数据库事务之外；测试前后重新检查角色和目标版本，避免验证期间撤权或修改后仍签发有效回执。

所有模型操作使用同一工作区行锁，与成员变更串行裁决。保存原子写入当前模型、不可变版本、已用回执。旧版本更新返回409；同回执同配置重试返回200及已保存资源（初次创建为201），不再次新建。回执已过期或资源已有后续版本时须刷新/重测，不自动覆盖。

当前版本号也保护启停、默认和撤钥操作。默认标志是工作区选择策略，不写入不可变配置；设置默认时清除同工作区其他模型的默认标志，不伪造其他模型配置内容变化。禁用清除默认。撤钥会清除密文、停用、取消默认并标记未验证，不能直接重新启用，须通过新测试后保存。

## 存储与访问边界

Goose **000005** 新增，既有1–4迁移保持原文：

| 表 | 内容与用途 |
| --- | --- |
| `platform_model_profiles` | 工作区归属、当前协议/地址/型号、名称说明、版本、启停/默认、视觉能力与验证时间；凭据是AES-GCM密文。 |
| `platform_model_profile_versions` | 每次保存的不可变配置快照；只保留模型/凭据引用，不复制可长期使用的明文或历史密钥。未来Session固定配置版本但须检查当前授权与凭据。 |
| `platform_model_probe_leases` | 工作区与操作者的在途探测租约，包含唯一claim和过期时间，不存凭据；防止多实例重复探测。 |
| `platform_model_test_receipts` | 回执哈希、调用者、目标版本、配置指纹、过期时间、合成测试结果和已保存资源；每次签发成功回执时惰性删除该工作区过期回执。 |

凭据密钥从部署 `KIKO_AUTH_SECRET` 以独立用途派生，AES-GCM附加数据绑定工作区和模型ID；备份恢复必须保留原部署密钥。更换根密钥不自动迁移旧密文，本期不提供轮换工具。普通JSON接口永不输出密钥/密文，只返回 `has_key`。

活跃成员可读取安全模型元数据；创建、测试、更新、启停、设默认、撤钥仅工作区 owner/admin。跨工作区引用及非成员访问拒绝。平台全局预置模型、运行时凭据分发、Agent引用及版本历史查看接口不属于本期接入，不能用Mock状态假装支持。

## 验收与限制

本批仅使用本地模拟模型服务及隔离 PostgreSQL，未使用真实用户密钥/外部收费模型。测试覆盖三协议请求、图文并发、图像通过/不支持/不确定、超时取消、输出遮盖、保存回执、工作区权限、并发版本及空库/v4升级。具体执行结果以交付记录为准；首次上线由 Event Hub 执行新迁移，Backend 不擅自迁移正式库。

新增表遵守 [数据库命名与所有权规则](../../docs/rules/database.md#建模与查询)，前缀不表示独立数据库或独立迁移链。

### 模拟提供方边界

正常 Backend/Event Hub 启动不创建或连接内置模拟模型。独立手工验收模拟服务不随开源仓库分发，须在仓库外单独管理、启动和停止；浏览器验收常驻夹具已移出仓库。自动化测试中的 `httptest` 短生命周期替身仍保留，用于验证协议、超时和错误分支，不进入生产构建。`model_fixture.go` 生成真实图片探测输入，属于正式诊断逻辑，不是模拟模型服务。
