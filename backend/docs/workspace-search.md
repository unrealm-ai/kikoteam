# 工作区搜索

顶栏调用 `GET /api/v1/workspaces/{workspace_id}/search?q=...`。必须先验证登录和当前工作区成员身份；使用每类已有的资源权限，最多返回各 5 条结果。

- AI 员工按名称或职责搜索，仅返回概览字段。
- 任务复用任务列表的标题/ID 和可见性查询，不搜索日志、正文或产物。
- 对话只搜当前读者自己的 Web 私聊，且必须已创建对话 Session。支持标题、员工名和对话 ID，不搜消息全文。
- 不提供飞书、钉钉、企微群名，也不搜索事项、技能或插件。

工作区切换、请求取消和搜索词更改后，前端不展示旧响应。单类查询不可用时标明，不当成无匹配。结果跳已有详情页面，打开后仍走该资源自己的鉴权。
