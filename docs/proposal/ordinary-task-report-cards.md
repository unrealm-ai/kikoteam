# 普通任务主动回告的任务详情链接

状态：已实施。现行行为见[任务详情链接规范](../spec/public-task-detail-links.md)。

用户消息轮可对本对话派生的普通任务发送详情链接，不按历史投递去重；`send_task_detail_link` 收业务 `task_id`、可选 `text`。主动回告轮只能发本轮可信回告的任务；有效卡片或链接已送达、正在投递或状态未知时给模型具体原因。过期或已撤销不拦新回告。Hook／定时仍走独立通知链路；飞书回写统一提示任务详情链接可查看，不提实际卡片或兜底形式。

验收：通过 MCP 检查渠道与权限；用真实 PostgreSQL 验证错误任务、历史送达、过期、并发与用户重发；验证卡片正文、原文加链接降级、未知不重发和送达后的不触发记录。回告带说明的卡片承担正文交付，附件不受影响。
