# 简化 SMTP 配置

状态：已实现，前端回归、隔离 PostgreSQL 和本地 TLS 夹具已验证。现行行为见[平台服务设置 Spec](../spec/platform-service-settings.md)。

## 设置入口

仍由平台管理员在「设置 → 平台管理 → 邮件与注册」管理。SMTP 连接只提供两种方式：

| 类型 | 管理员填写 | 服务端推导 |
| --- | --- | --- |
| 网易 163 邮箱 | 163 邮箱地址、客户端授权码（不是网页登录密码） | 使用固定的 163 SMTP 预设，管理员无需填写服务器或 TLS 选项 |
| 自定义 SMTP | SMTP 服务器 DNS 地址和端口、发件邮箱、可选的 SMTP 用户名、服务器要求的密码或客户端授权码 | 只支持 `465`（连接即 TLS）和 `587`（必须成功升级 STARTTLS），证书按所填 DNS 主机名校验 |

163 模式以发件邮箱认证，自定义模式可用独立 SMTP 用户名，留空默认以发件邮箱认证。不能分别指定 envelope/Header 发件人、证书校验名或 TLS 模式。自定义地址示例：`smtp.example.test:587`。不提供高级认证或免认证中继；拒绝 IP 地址、URL、其他端口和明文降级。缺少 STARTTLS、证书无效或主机名不匹配均视为失败，不能发送认证材料或邮件。

## 保存、启用和兼容

- SMTP 连接参数、邮件启用和邮箱验证码注册策略是不同设置项。只有首次打开确实未配置的新实例时，**表单草稿**默认勾选「启用邮件」和「注册时必须验证邮箱」；已配置、已显式停用或由旧部署提供配置时按实际状态显示。在管理员保存前，数据库和对公网的注册策略保持原样。选择预设、填写连接参数和试发均不改变生效值。
- 试发只送给当前平台管理员的账号邮箱，不持久化候选 SMTP 设置或秘密，也不变更当前生效值；SMTP 接收不表示送达。启用状态下保存前，必须先成功试发，保存时由服务端验证近期试发凭据与操作者、当前配置版本、SMTP 目标及有效认证材料相符。连接或凭据变化、版本冲突、凭据无效或超时须重新试发，单独的注册开关不参与连接/认证匹配。试发凭据不含明文 SMTP 秘密。停用不要求试发，可直接尝试保存，但仍必须通过并发版本与防管理员失联检查。
- 旧数据库值和旧部署配置中可能有不同的认证账号、发件人、校验名、端口或免认证配置。打开页面不得静默改写、推导或把旧秘密套入新身份/服务器；无法安全表示为新表单的配置应告知管理员，并允许填写完整新配置显式替换。替换验证失败不覆盖旧有效配置。停用保留原连接及密文凭据，不得借停用写入新连接或秘密；显式保存的停用值不回退部署配置。

## 计划验收

| 场景 | 预期结果 |
| --- | --- |
| 163 模式及切换到自定义 | 只展示各模式字段；163 使用固定预设，以邮箱认证并发信，授权码不回显；切换模式不把旧凭据悄悄送给新服务器 |
| 自定义 465 和 587 | 本地 TLS 夹具独立验证 465 隐式 TLS、587 强制 STARTTLS，两者都校验 SMTP DNS 名；TLS 失败时不尝试明文认证或发送 |
| 伪造字段、IP/URL/非法端口、免认证或空认证账号 | 不经 UI 直接调用也无法启用未批准配置；测试无外发、无保存 |
| 初始表单和公开策略 | 真正未配置时首次草稿默认勾选两个开关，刷新或试发前后公开注册策略不变；已启用、已停用和旧部署沿用实际状态；显式保存才使策略生效 |
| 试发和策略 | 合成账号验证只能试发给操作者邮箱；试发成功或失败均不保存候选配置或修改公开策略。启用状态保存没有有效成功试发依据时拒绝；同版本、同用户、同目标和凭据可在有效期内保存；目标/秘密/版本/用户变化、凭据过期、缺失或被篡改均拒绝并要求重试。修改注册开关不另要求试发；停用无需试发，仍检查锁定保护 |
| 旧数据与旧部署配置 | 分别覆盖可表示和不可表示的旧配置、手动换成新配置、失败保留旧生效值；未显式替换不经运行时或前端自动改写，不能复用不匹配的旧密码 |
| 安全、并发和既有认证 | 普通用户和工作区管理员不能访问；校验 CSRF、秘密脱敏、版本冲突、防管理员失联和既有注册/恢复路径。用隔离 PostgreSQL 核对保存决策 |

本地模拟/TLS 夹具与真实供应商验收分开记录；没有真实授权测试之前，不宣称 163 账号已验证或邮件已送达。
