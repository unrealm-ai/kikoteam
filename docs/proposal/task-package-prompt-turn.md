# 任务提示词中的能力包名称和说明

状态：已实施，专项验证通过。

保留当前实现：任务员工身份沿用任务创建时配置；已获准能力包的名称和说明按执行轮次取快照，保存后的新文案从下一轮起使用。未开始首轮的现有任务也遵循此规则。只更新测试和正式行为基线，不改变能力包成员、资源升级、权限或执行逻辑。

验收：用隔离 PostgreSQL、真实 Engine/Pi 和本地测试模型检查首次运行前后的包文案，在同一旧任务的后续轮次看到新文案且员工仍未改名，在新任务看到新员工名；另运行既有能力包资源升级端到端用例。

结果：员工提示词和既有能力包升级两项端到端均通过，Backend lint 与 API 契约全绿。见[正式行为基线](../spec/task-package-prompt.md)。
