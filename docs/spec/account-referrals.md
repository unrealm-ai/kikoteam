# 账号拉新邀请

- 「设置 → 平台管理 → 用户管理」提供「邀请拉新奖励」开关，默认关闭。开启后，登录工作台顶部显示「邀请得积分」。
- 每个账号可生成一条长期有效的 `/r/<code>` 链接，不关联工作区和角色。链接打开现有注册页，已有用户可以切换到登录；注册和登录均不会通过该链接加入邀请人的工作区。
- 新账号注册时确定邀请人。验证码注册立即验证邮箱；密码注册先记录归因，待通过邮箱验证码验证（当前使用重置密码流程）才发奖。邀请人每个合格的新账号得 100 积分，流水显示「邀请奖励」。新账号原有注册赠送不变。登录、同邮箱重复注册、无效或撤销码均不发奖。
- 开关关闭后，旧链接仍可用于注册或登录，不产生奖励。重新开启后旧码继续可用；关闭期间注册及旧代次未结算的奖励均不补发。已到账不撤回。
- 工作区邀请路径、成员权限和有效期不变。生产版 Google OAuth 注册未开放，演示登录和插件 OAuth 不接入奖励。

数据模型、接口和实现约束见[设计稿](../proposal/account-referrals.md)。数据库迁移 `000102` 不修改旧的邀请数据或积分流水；发布时先应用迁移再部署使用该功能的应用，保留迁移可回退应用。不应回退已产生奖励的数据库结构。
