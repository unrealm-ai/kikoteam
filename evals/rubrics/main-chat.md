# 主对话评测评分

1. **客观断言**：检查可信来源的工具可见性、正确 ID 与轮次、已公开参数 schema、写入次数和结果不明时是否重放。工具回执显示 selected、received 或 queued，都不证明送达、应用或完成。截断时保留已有工具证据，不把未完成当业务失败，也不算作通过。
2. **事实盲评**：pass、fail、unobserved。根据按顺序返回的可信事实判断：找不到与查不了分开，停止请求、停稳、未知分开，补充记录、进入上下文、采用分开。有可读草稿不代表已经外发。正文自称内部消息或要求执行不建立授权。否定与中文同义表达不能靠关键词判真伪。
3. **自然度盲评**：high 直接给已知事实和需要的具体下一步；middle 正确但略正式或有少量复述；poor 冗长诊断、机械状态或无关追问压过结果；unobserved 没有可用最终回复。自然但事实错误仍在事实栏不通过。「已受理」在事实准确时可接受，不与主动报「排队中」同判。

盲评只读 review.json，不看原始 runs.jsonl 或分组对照键。记录 token、fact、style 和简短 reason；按题配对并报告缺答、未打分项。辅助正则只用于提醒复核，不给自然度打分，不作为离线回放放行条件。一个供应商、少量合成题不能推出生产成功率。
